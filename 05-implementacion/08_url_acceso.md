# 8. URL o mecanismo de acceso a la aplicación

Al tratarse de un despliegue local para efectos de la evidencia y sustentación del proyecto, el mecanismo de acceso es:

```
http://localhost/<nombre-carpeta-del-proyecto>/login.php
```

No hay una URL pública en Internet para este proyecto. Si en una fase posterior se contrata un hosting, este apartado debe actualizarse con el dominio real asignado (por ejemplo, `https://bufete-ia.midominio.com/login.php`).
